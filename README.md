# MicToggle

Кнопка play/pause на Bluetooth-наушниках (и клавиатуре) выключает и включает микрофон во всей
системе macOS — в любой программе для звонков (Толк, Zoom, Telegram, Meet…), даже если её окно
свёрнуто. Зачем: синхронизация mute в программах звонков обычно работает только с AirPods.

*Mute your Mac's microphone system-wide with the play/pause button of any Bluetooth headphones.
Meet mode / Music mode, switchable from the menu bar or by pressing the keyboard play key N times.*

## Скачать

[Releases](https://github.com/romc/mictoggle/releases) → `MicToggle.zip`. Внутри программа и
`README.txt` с инструкцией по установке. Требуется macOS 13+, Apple Silicon или Intel.

Программа не нотаризована Apple: при первом запуске откройте Системные настройки →
Конфиденциальность и безопасность → «Всё равно открыть» (или
`xattr -dr com.apple.quarantine /Applications/MicToggle.app`).

## Как работает

- **Meet mode** — кнопка наушников выключает/включает микрофон: громкость входа 0 (+ mute, если
  устройство умеет). Значок 🎙/🔇 в строке меню, надпись и звук.
- **Music mode** — кнопка, как обычно, управляет музыкой.
- Если кнопку забрал другой плеер (Яндекс Музыка, голосовое в Telegram), MicToggle возвращает
  её себе, как только тот затих или начался звонок.
- Режим (меню «Кнопка наушников»): только во время звонка (пока микрофоном пользуется какая-то
  программа — по умолчанию), всегда, не перехватывать. Смена режима объявляется голосом.
- Опционально: клавиша play на клавиатуре — одно нажатие как кнопка наушников, 2/3/4 быстрых
  нажатия — смена режима (нужен «Универсальный доступ»).

Под капотом: приложение регистрируется как «текущий плеер» (`MPRemoteCommandCenter`), поэтому
macOS отдаёт ему команды play/pause с наушников вместо запуска Музыки. Микрофон — через CoreAudio.

Ограничения: программа звонков не знает, что микрофон выключен, и показывает его включённым;
«автоматическая регулировка громкости» в программе звонков может поднять уровень обратно — её
лучше выключить.

## Сборка и установка из исходников

```
./make-signing-cert.sh   # один раз: локальный сертификат для подписи
./build.sh install       # собрать, поставить в /Applications и перезапустить
```

- `./build.sh` без аргументов — только `build/MicToggle.app` (universal) и `dist/MicToggle.zip`.
- `make-signing-cert.sh` кладёт самоподписанный сертификат «MicToggle Local Signing» в
  login-связку ключей (копия — `~/.config/mictoggle-signing`). С ним подпись у всех сборок
  одинаковая, и разрешение «Универсальный доступ» переживает пересборку. Без него `build.sh`
  подписывает ad-hoc — тогда после каждой сборки MicToggle нужно удалить из «Универсального
  доступа» кнопкой «−» и добавить заново.
- После первой установки: включить «Запускать при входе» в меню значка и (для клавиши play
  на клавиатуре) добавить `/Applications/MicToggle.app` в «Универсальный доступ».

Нужны Xcode Command Line Tools (`swiftc`). Исходник — `main.swift`, иконка рисуется
`makeicon.swift` при сборке.
